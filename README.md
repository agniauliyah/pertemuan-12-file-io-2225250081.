## Deskripsi

Repository ini berisi hasil praktikum Algoritma dan Pemrograman Pertemuan 12 mengenai File Input/Output (File I/O) dan Error Handling menggunakan Python.

## Struktur Folder

- `data/` — Berisi file data masukan dan keluaran.
- `latihan/` — Berisi program latihan File I/O dan Error Handling.
- `tugas/` — Berisi program tugas rekap nilai dari file.

## Materi

1. Menulis file menggunakan Python.
2. Membaca file.
3. Menambahkan isi file (append).
4. Memproses data dari file.
5. Menangani kesalahan file tidak ditemukan.
6. Menangani kesalahan input menggunakan `ValueError`.
7. Membuat rekap nilai dari file.
